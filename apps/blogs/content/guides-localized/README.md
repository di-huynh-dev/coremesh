# Guide translations / Bản dịch hướng dẫn

English originals live in `../guides`. Vietnamese translations live in `vi`, with matching guide folders and chapter filenames. The EN/VI language switcher opens the same guide or chapter in the selected language.

Bản gốc tiếng Anh nằm trong `../guides`. Bản tiếng Việt nằm trong `vi`, giữ cùng tên thư mục và tệp chương. Nút EN/VI chuyển ngôn ngữ cho đúng hướng dẫn hoặc chương đang đọc.

The Vietnamese edition was machine translated, with technical terminology adjustments. Code examples, inline code and link destinations are preserved. Keep both editions in sync when adding or editing a chapter; review translations against the English source when technical precision matters.

Bản tiếng Việt được dịch tự động và đã chỉnh một số thuật ngữ kỹ thuật. Các ví dụ mã, mã nội dòng và đích liên kết được giữ nguyên. Khi thêm hoặc sửa một chương, cần cập nhật cả hai bản; đối chiếu với bản tiếng Anh khi cần kiểm tra độ chính xác của nội dung kỹ thuật.
